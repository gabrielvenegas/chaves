# CHAVES Keyboard Shortcuts

## Navigation
- **Ctrl+L**: Toggle between AI Chat and Development Pane (tmux). ✅
- **PageUp / PageDown**: Scroll message history. ✅
- **Home / End**: Jump cursor to start/end of input line. ✅
- **Esc**: Reset scroll to bottom and clear unread count. Also closes help overlay. ✅
- **g / G**: Jump to bottom / top of message history (vim-style, when input is blank). ✅

## Editor / Input
- **Ctrl+K**: Clear current input draft. ✅
- **Ctrl+U**: Clear the current line of input. ✅
- **Alt+Enter** / **Ctrl+J** / **Ctrl+O**: Insert a newline without submitting. ✅
- **Up / Down**: Navigate command/file picker. Scroll history when input is blank. ✅

## System / UI
- **Ctrl+C / Ctrl+Q**: Quit CHAVES safely. ✅
- **Ctrl+R**: Force refresh / re-index current file changes. ✅
- **Ctrl+T**: Cycle through available themes (Warm, Slate, Forest). ✅
- **Ctrl+H** (or **?**): Toggle a help overlay showing all shortcuts. ✅

## Channel Filters
- **Alt+1**: Show all messages (Default). ✅
- **Alt+2**: Show only Chat messages (user + assistant replies). ✅
- **Alt+3**: Show only Proactive Insights. ✅
- **Alt+4**: Show only Terminal Logs. ✅
